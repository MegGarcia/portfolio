# Low-fidelity (doodle) overrides

the password**, each mockup below is replaced by a hand-drawn "doodle" version so
the confidential hi-fi designs aren't shown. Drop a doodle PNG in this folder
using the **exact same filename** as the original, and it will be used
automatically in preview mode. (Signed-in visitors still see the real hi-fi
image.)

Recommended: white background, PNG, roughly the same aspect ratio as the
original (resolution doesn't need to match).
